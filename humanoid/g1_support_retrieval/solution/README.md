## 全程录像要求

所有后续仿真执行、调试和验证都必须录制视频，成功、失败、提前停止均保留。从初始化完成的场景开始记录，并保存停止时的末帧；不得只保留成功片段。当前两个运行入口默认以 25 FPS 保存 `motion.mp4`，与本轮轨迹、结果放在同一 `runs/` 目录。输出目录已有内容时，自动新建带时间戳的同级目录，避免覆盖历史实验。异常退出会尝试补录末帧并关闭视频；进程被强制杀死或渲染器崩溃不能保证视频完整，必须注明录像缺失。离线规划结果如做可视化回放，也必须录像，并明确标为参考轨迹而非物理执行。

后续方案统一放在此目录下，按动作任务分子目录；代码、参数、复现命令及本机实验记录一起保存。原有 `agile.py`、`kinematics.py` 保留。

**已确认可用的四项技能**（推箱子、搬凳子、爬上箱子/凳子、搬箱子）汇总在 [`../verified`](../verified/README.md)，每项都有一键脚本，跑完会自动复核。
