Hanoi · 桌面汉诺塔：跨身体工具使用Tabletop Tower of Hanoi: cross-embodiment tool use

固定骨盆的 G1 在桌面三杆汉诺塔场景中借助工具搬运带孔圆盘：每次只搬一个顶盘、大盘不得压小盘、整盘须越过杆顶并完全释放。十个独立任务按末端（Dex3、平行夹爪、Inspire 五指手）、能力公开或隐藏、夹持／腕力矩边界以及盘数分别登记，考察跨身体工具相性、能力边界判断与 self-modeling。场景提供 T1 侧夹钳与 T2 底部托叉，当前十项参考均以 T2 完成。A fixed-pelvis G1 moves annular disks between three rods on a table using tools: only one top disk moves at a time, a larger disk may never rest on a smaller one, and each disk must clear the rod top and be fully released. Ten separate tasks vary the end effector (Dex3, parallel gripper, Inspire five-finger hand), disclosed versus hidden capability, grip or wrist-torque boundaries, and disk count, testing cross-embodiment tool compatibility, capability-boundary judgment and self-modeling. The scene offers T1 tongs and a T2 under-disk fork; all ten current references use T2.
