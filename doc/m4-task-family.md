# M4：跨身体牵引运输任务族

更新：2026-10-28。范围：任务设计、开发执行与证据记录。

合并为 **6 个主变体**，每种 embodiment 一个。统一场景为“起步 → 直道 → L 形转角 → 目标停稳”。负载、摩擦、通道宽度、工具配置和随机种子作为实例参数，不重复计数。

已实现 6 个变体的专家候选、计划、轨迹记录、物理监测与视频；本轮 6/6 有固定配置完整见证并通过离线复核。历史双 Go2 base/hard 证据保留；当前记录不表示随机域覆盖、团队必要性、真实手部抓握或自主连接已经验证。正式准入状态不变。

## 与 M2 的边界

按运输时的承重方式和力传递机制划分，不按机器人型号划分。

| 维度 | M2：协同持物搬运 | M4：地面支撑下的牵引运输 |
| --- | --- | --- |
| 主要承重 | 机器人通过手部接触承托货物 | 地面通过滑台、拖车等支撑货物 |
| 核心能力 | 合抬、载荷分配、抓持保持、同步下放 | 牵引能力、张力分配、松紧切换、转向力矩 |
| 典型恢复 | 临时放置、换抓点、重新合抬 | 松绳、调整队形、改变牵引方向或经验证的连接配置 |
| 证据重点 | 承托接触、离地保持、下放和释放 | 地面支撑、足端滑移、牵引载荷、绳索与货台扫掠 |

双 G1 抬箱、抬搬运支架或悬空承重运输归 M2；双 G1 拉动地面支撑的货台归 M4。M4 中手部抓握用于保持牵引接口，不等同于抬起货物。装载—牵引—卸载如成为完整目标，应单列复合流程并验证阶段交接，不能用一个阶段的成功替代另一任务族的成功。

## 合并计数规则

- 直线牵引、启动阻力测试并入能力探针，不单列任务。
- 轻／重载、高／低摩擦、宽／窄通道作为难度参数；原 base/hard 保留独立配置与结果，但归入 M4-01。
- 绳索、把手、拖杆作为工具配置；每种接口独立验证，不新增主变体编号。
- 单 Go2 作为 M4-01／03 的能力对照，不列第七个主变体。
- 团队选择、能力不对称、受阻恢复作为评测条件，不复制任务条目。
- 自主连接、装载、解绑另设扩展模块；首版采用预装载、预连接初态。

能力边界使用“已见证成功／预算内未找到解／有必要条件证据的不可行”区分。单机控制器失败不能证明协作必需；三机并排失败不能证明所有三机队形失败。若第三台可在不干扰的位置闲置，需测是否值得调用，而非预设三台可用比两台更不可行。

原预连接绳索的 400 N 额定值与 50 mm 脚端滑移约束保留在对应历史配置；G1 接口承载与双足监测另验。150 N 自主连接器台架证据不与原绳索参考混用。真实抓握不能由焊接连接替代，自主重配置不能由远程修改连接状态替代。
