# Model provenance

The Panda arm URDF and collision meshes are vendored from the installed
Genesis 1.4.3 `assets/urdf/panda_bullet` distribution. Its Apache License 2.0
text is retained in `assets/panda/LICENSE.txt`, and the original URDF is retained as
`assets/panda/original.urdf`. This is the PyBullet-derived Panda simulation model.

Task modifications, generated by `assets.py`:

- Use the existing collision meshes as lightweight visuals.
- Retain the authored joint geometry, limits, masses and simplified inertia
  tensors. These are simulation assets, not a calibrated hardware digital twin.
  In particular, the upstream wrist inertia elicits a Genesis diagnostic; it
  is retained consistently rather than silently changed between runs.
- Add a fixed 100 g tool with an 8 mm spherical contact pad and a shaft.
- Generate the 200 g disk as one closed 128-sided convex prism, with matching
  polygon inertia and a non-colliding, one-sided heading stripe.

Both arms are full dynamic articulations. The disk has a free root and no
attachment, weld, planar slider or commanded pose. The fixed tool attachment
joins the pad to the robot only. The table supports the disk through contact.

The task controller and scene are independently implemented here. No source
code from Stein Variational DRO or DART is bundled. Those projects informed the
design discussion; their success claims are not evidence for this task.
