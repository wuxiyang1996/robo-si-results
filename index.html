robo-si：已验收的具身任务robo-si: accepted embodied tasks

robo-si 是一个面向自我建模、工具发现、负载移动与多机器人协作的机器人基准。本站整理作者已签收的任务与任务族：每个配置给出条件、任务设计、可用工具、embodiment，以及该配置的正确行为是否为拒答（不可完成，机器人应空手进入退出区并站稳）。robo-si is a robotics benchmark for self-modeling, tool discovery, loaded locomotion and multi-robot cooperation. This site lists the tasks and task families the author has signed off: for every configuration it gives the conditions, task design, available tools, embodiment, and whether the correct behaviour is refusal (the task is infeasible, so the robot should exit empty-handed into the exit zone and stand still).
