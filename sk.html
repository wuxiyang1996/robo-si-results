SK · Sokoban：双 G1 隐藏地图推箱清路Sokoban: two-G1 hidden-map box clearing

两台 G1 在未知的分室地图中探索，只凭各自第一视角 RGB、本体感知、自身目标标识和收到的显式消息构建并更新全局地图，通过物理推箱清理通路，最终同时稳定驻留在各自的目标区；箱子没有交付目标，只能推，不能抓、拉、抬。核心问题是能否从局部观察构建一致、可更新的全局地图并据此行动，以及显式通信（C+）相对无显式通信（C−）是否改善建图与执行。软件工具可由 agent 在私有沙盒内按需编写，实体工具不是通关要求。Two G1 humanoids explore an unknown divided-room map and, using only their own first-person RGB, proprioception, own goal identity and explicitly received messages, build and update a global map, physically push crates to clear routes, and finally both hold steady in their own goal zones; crates have no delivery targets and may only be pushed, never grasped, pulled or lifted. The core question is whether robots can build a consistent, updatable global map from local observations and act on it, and whether explicit communication (C+) improves mapping and execution over no explicit communication (C−). Agents may write software tools in a private sandbox as needed; physical tools are not required.
