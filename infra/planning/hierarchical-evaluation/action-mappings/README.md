## 审阅方法

1. 从 `skills[].actions` 读取动作顺序及支撑变化；相邻动作的退出条件应能支持下一动作进入。
2. 通过 `evidence_ids` 找到原始事件；按 `source` 的 SHA-256 和 JSON 指针复核。`first`/`last` 保留原始测量摘录，删减的长数组明确标注。
3. 区分全程时钟、局部时钟、完成点与阶段起点；未解决的偏移不能用于声称连续接续。
4. 对照真实状态与控制器来源核对接触、支撑和可达性，再填写 HL→LL、LL→TRAJ、HL→TRAJ 联合结论。事件名称本身不产生通过结论。

Hanoi 的选盘是离散决策，K01–K04 随七次移动重复；H3 仅 heavy_prop，A/B 同时操作可重叠；M2/M4 仍需在较长的 carry/tow 阶段内部定位直行与转角。

H5 已补足原来 31.90 s 抬升里程碑之后的动作：31.00 s 踩压事件→45.08 s 双足上平台→67.16 s 插托架阶段结束→100.66 s 下平台结束→105.40 s 转入推运→150.98 s 完成。31.90 s 是评分里程碑，不是准备动作结束。
