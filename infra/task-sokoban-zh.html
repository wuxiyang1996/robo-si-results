任务范围与场景

四箱开发地图；自身 RGB、本体感知与显式消息；单次完整实验见证

Gamma 8011370：279.18 s、24 个高层操作、76 个低层段；两机到各自目标并保持 3 s。独立采样审阅及完整公共输入回放通过；task_success=null。

两台 G1 在未知地图中推箱清路，各自到达对应颜色的目标；箱子本身没有交付目标。网格 0.9 m，4 个箱子各 0.65 × 0.65 × 0.55 m、4 kg、摩擦系数 0.4。当前证据仅为 Gamma 8011370 的一个开发地图连续见证，不代表未见地图泛化。

Sandbox README · Agent SDK

每台机器人仅使用自己的 RGB、本体关节与惯性观测、目标标识和收到的显式消息，无全局地图、箱子真值位姿或隐藏同伴状态。消息上限 256 UTF-8 字节、每接收者最多 16 条待处理消息。各提交 43 个绝对关节目标；双机目标齐备才推进共享世界一步。控制 50 Hz；原生仿真配置 dt=0.005 s、control_decimation=4。开发感知依赖已标定惯性增量、平地、已知网格和颜色材料。
