01 · 任务描述

目标、场景与接口

给 agent 的指令（原文）

将蓝色套筒和红色顶盖依次装到铰接平台的矩形定位柱上，形成释放后仍能稳定保持的装配结构。

本版本仅包含第一层基础场景：铰接平台、基础支撑工具、套筒和顶盖。

完成条件与公开约束：

1. 插入套筒前，平台须保持水平、低速，并由桌面上的已释放物体通过真实接触持续承托，稳定 0.5 秒。支撑可以由一个或多个物体组成。 2. 套筒须套在定位柱上、落座于平台，释放稳定 0.5 秒后才能插入顶盖。 3. 顶盖须套在同一定位柱上并落座于套筒。工具对平台的支承必须持续存在。 4. 最终所有物体都须低速、脱离机器人全部接触，结构连续保持 2 秒。

评分依据实际状态与承载关系，不限定使用哪个支撑物体、摆放点或机器人动作路线。机器人身体不能代替释放后的支撑链；两个装配零件不能同时插入。矩形孔绕竖直方向旋转 180° 可以配合，旋转 90° 不满足配合条件。

用机器人关节动作完成任务。物体必须依靠真实接触运动，不得直接改写位置、瞬移、焊接、吸附或绑定到手上，也不得伪造接触与状态数据。

只有完整成功才得 1 分，中间阶段不计分。错序装配、建立后连续 0.1 秒失去支撑资格、物体掉落或超过 120 秒会失败。再次接触或结构失稳会中断最终保持计时。

场景使用固定骨盆的 G1，控制 43 个关节，控制频率 50 Hz、物理频率 200 Hz。手臂力矩上限可能为标称值的 85%–100%，本回合的实际限值由控制接口公布；初始手臂姿态可能有小幅变化，应读取关节传感器。

场景与接口（供评审）

固定骨盆 Unitree G1，Dex3 双手，43 个绝对关节目标。控制频率 50 Hz，物理频率 200 Hz，固定增益 PD 与真实力矩上限。评测 agent 使用机器人传感器；参考专家读取开发真值，二者成绩不混用。

仅第一层：铰接平台、基础支撑工具、套筒和顶盖。无远端重块、无固定干扰块。五个固定种子、两个范围边界和一个名义场景，共 8 个输入；随机范围保持原值。grade 使用 --randomized 时按回合随机化。

有限场景覆盖不等于认证全部连续组合。全部物理参数与精确随机范围见 任务规格及下方源码。

03 · 评分标准

成功必须在物理世界中成立

仅完整物理成功得 1 分，否则为 0 分。 阶段进度用于诊断，不是最终分数。任务评分、独立终态检查和监视器必须一致通过。

  1. 先稳定支撑平台 0.5 秒：桌面 → 已释放承载物体 → 平台。
  2. 套筒正确套柱并落座于平台，释放稳定 0.5 秒后才可插入顶盖。
  3. 顶盖落座于套筒，平台支撑链持续存在。
  4. 全部物体脱离机器人接触并低速稳定 2 秒；完整成功才得分。

承载评分不限定工具身份或摆放点。各有效向上接触力须大于 0.05 N，全部承载分支接地且释放；手持分支、悬空循环、未知承载体与缺失测量不通过。连续 0.1 秒失去已建立的支撑资格会失败。

验收时具体看什么

  • 物体依靠真实接触运动；没有瞬移、绑定、吸附、伪造接触或改写评分。
  • 阶段顺序与释放稳定条件确实发生；最终状态达到指令要求。
  • 没有明显穿透、异常能量、抖动取巧或依靠机器人持续扶持的假成功。

全量检查包含正例、零分 no-op、真实特权瞬移反例、38 项容器逃逸探针和完整性检查。
