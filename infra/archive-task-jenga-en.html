Jenga: extraction and restacking

Extract three different non-top pieces, restack them on the tower, then release the stable structure.

Declared scope

Fixed-pelvis G1 with two Dex3 hands; only the declared seed 0 profile is verified. Three complete runs start from independent resets, followed by a separate action replay. The default smaller development scene and other randomized profiles are outside this evidence.

Four alternating layers of three pieces; the declared profile uses 400 × 52 × 55 mm pieces, 2 mm lower centre pieces and 30 mm additional finger clearance.

Interface and observations

43 joint-angle targets, 50 Hz control and 200 Hz physics evaluation, with model torque caps and PD control. The reference reads privileged object poses, velocities and contacts. It uses no object-pose action, attachment or external-force action.

Reference plan

The reference selects centre pieces from layers 2, 3 and 0, placing them in top slots 0, 2 and 1. It uses an end grasp and central regrasp, a sideways extraction and rotation, then a staged table-supported pull and carry. Contact and pose feedback correct the motions. This order is specific to the declared profile.

Scoring

Horizontal clearance must precede lifting. Each placement needs measured tower support and a quiet, released 0.4-second dwell. All three placements must then remain released and stable for 3 seconds. Protected-piece motion over 18 mm, orientation error over 15 degrees, drops or timeout fail the task. The score is binary.

Execution and replay evidence

All 3 declared complete runs passed, with a separate full action replay. The representative run lasts 432.365 seconds. There are also 12 passing static mechanical diagnostics; these contain no robot action and are not expert runs. Development failures are retained separately.
