# H1 · 支撑物取物：参考解设计

已有声明范围内的参考执行见证；本文补齐统一设计说明。本次新增物理运行：0。

## 设计思路

先把支撑物搬到取物区，再登高、取物、下降和交付。支撑物位置决定足部落点和上肢可达性；登高前必须形成稳定支撑，不能以取物评分时间替代落脚完成时间。
