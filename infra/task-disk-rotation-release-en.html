What the controls establish

  • DR-02: the existing fixed_contacts policy succeeds in 31.94 s and 34.40 s on the same two hidden scenes where the adaptive reference times out. Material sectors alone do not establish recontact necessity.
  • DR-04: fixed_contacts hits an unexpected collision at 14.02 s; the recontact reference succeeds on nominal and three perturbed configurations. This compares these controllers, not every possible fixed-contact strategy.
  • DR-05: an override-merge bug caused a zero-step startup exception. The corrected physical dual-arm control succeeds in 43.54 s, versus 98.50 s for the nominal single-arm reference. The original error is retained as an infrastructure failure.
  • DR-09: in the same paired scene, Panda-only times out acquiring contact and Stretch-only collides. The cooperative reference succeeds; this does not prove all solo strategies infeasible.
  • DR-08: direct two-hand contact succeeds without using an aid. Tool necessity remains unestablished.

Interface validation scope

Agents receive robot-mounted RGB, joint proprioception, the public goal and joint limits. Stretch includes its URDF-calibrated head camera. Object truth, material values, rewards and simulator setters are absent. Development uses a process; evaluation uses Bubblewrap namespaces and a read-only OCI filesystem, exposing only the delivery workspace and authenticated RPC.

No-op is a valid zero; denied operations produce VOID; grading restarts in fresh workspaces. A public reference action tape completes through the interface, an open-loop integration witness rather than an independent coding-agent result.

Formal admission boundary

Signed human video review, second-person reproduction and independent coding-agent closed-loop results remain pending. The mobile model is Stretch 3; G1 has an anchored pelvis. DR-I01 remains unknown. Physical limits and the shared admission checker are unchanged; no human signatures are fabricated.
