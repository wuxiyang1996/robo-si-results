# G1 在桌面搭汉诺塔

桌上有三根杆，圆盘按大盘在下、小盘在上的顺序叠在其中一根杆上。把整叠圆盘移到底座为绿色的目标杆上，仍按大盘在下、小盘在上的顺序叠好；第三根杆可用于中转。默认有 3 个圆盘，任务也支持 4 或 5 盘。

每个回合的场景都可能不同：起始杆和目标杆、三根杆的位置、杆高、圆盘的大小和颜色、圆盘的质量和摩擦都会变化，须通过机器人自身的传感器观察。圆盘的颜色与大小没有固定对应关系。

每次只能选择某根杆最上面的一个盘。用手抓住它，向上提到整个盘都越过杆顶，再搬到另一根杆上方，对准盘孔后放下。空杆可以接收任何盘；已有盘的杆只能接收比顶盘更小的盘。

圆盘放好后，机器人所有部位都要离开它，让它在底座或正下方的圆盘上稳定保持 0.5 秒，才算完成这次移动。前一次移动完成后才能开始下一盘。允许合法的额外移动；提起后放回原杆不增加移动次数。

最后，所有圆盘都必须位于目标杆，正确叠放、受到支撑，并完全脱离机器人接触，再连续稳定保持 2 秒。默认总时间限制为：3、4 盘 180 秒，5 盘 420 秒。移动非顶盘、同时移动多盘、大盘压小盘、横穿杆或掉落都会导致失败。

G1 的骨盆固定在支架上，使用双臂与手操作桌面物体，通过 43 维关节动作接口控制。应通过真实接触完成抓取和放置，不得直接改写物体位置、把盘绑定到机器人、伪造接触或修改评分状态。

手臂力矩上限可能为标称值的 85%–100%，本回合的实际限值由控制接口公布；初始手臂姿态可能有小幅变化，应读取关节传感器。

只有完整任务成功才得 1 分，否则为 0 分。最少 7、15、31 步分别对应 3、4、5 盘的符号解；这些步数不提供机器人动作轨迹。
