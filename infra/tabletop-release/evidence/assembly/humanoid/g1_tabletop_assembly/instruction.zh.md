# G1 工具辅助桌面装配

将蓝色套筒和红色顶盖依次装到铰接平台的矩形定位柱上，形成释放后仍能稳定保持的装配结构。

本版本仅包含第一层基础场景：铰接平台、基础支撑工具、套筒和顶盖。

完成条件与公开约束：

1. 插入套筒前，平台须保持水平、低速，并由桌面上的已释放物体通过真实接触持续承托，稳定 0.5 秒。支撑可以由一个或多个物体组成。
2. 套筒须套在定位柱上、落座于平台，释放稳定 0.5 秒后才能插入顶盖。
3. 顶盖须套在同一定位柱上并落座于套筒。工具对平台的支承必须持续存在。
4. 最终所有物体都须低速、脱离机器人全部接触，结构连续保持 2 秒。

评分依据实际状态与承载关系，不限定使用哪个支撑物体、摆放点或机器人动作路线。机器人身体不能代替释放后的支撑链；两个装配零件不能同时插入。矩形孔绕竖直方向旋转 180° 可以配合，旋转 90° 不满足配合条件。

用机器人关节动作完成任务。物体必须依靠真实接触运动，不得直接改写位置、瞬移、焊接、吸附或绑定到手上，也不得伪造接触与状态数据。

只有完整成功才得 1 分，中间阶段不计分。错序装配、建立后连续 0.1 秒失去支撑资格、物体掉落或超过 120 秒会失败。再次接触或结构失稳会中断最终保持计时。

场景使用固定骨盆的 G1，控制 43 个关节，控制频率 50 Hz、物理频率 200 Hz。手臂力矩上限可能为标称值的 85%–100%，本回合的实际限值由控制接口公布；初始手臂姿态可能有小幅变化，应读取关节传感器。
