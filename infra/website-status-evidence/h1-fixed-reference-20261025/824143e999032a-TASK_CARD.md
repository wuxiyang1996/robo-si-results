## 给 agent 的任务

“把指定颜色的箱子从柜子取下，稳定放到地面绿色区域，双手离开后调用 finish。可以与房间里的物体交互。”公开约束为机器人关节控制、禁止修改世界与记录，以及指令末尾的五条安全规则（英文全文见 [relay_safety_rules.py](sandbox/trusted/relay_safety_rules.py) 的 `AGENT_SAFETY_RULES`）。指令不包含支撑物用途、层号、位置、物性、步骤或中转路线。

只有机器人自身传感器可用：关节编码器、电机力矩估计、骨盆/躯干 IMU、头部 RGB 和深度、头部 LiDAR、手部触觉与足底力。型号、安装位姿、频率、噪声和模拟限制由 [传感器实现](sandbox/trusted/sensors.py)及 [SDK](sandbox/agent_sdk/README.md)声明。世界坐标、物体身份索引、柜体几何、私有种子、评分与专家代码不进入 agent bundle。

L1 是本体传感的站立/行走，L2 是机器人自身模型上的目标规划，L3 是中间点及 IK/FK。允许 agent 自己实现感知与控制；不提供“搬凳”“取红盒”这类任务宏。能力披露 explicit / partial / latent 与难度层是两条独立轴。

## 世界与随机化

Genesis 1.4.3；物理 200 Hz、指令 50 Hz；G1 + Dex3 共 43 关节。每关节力矩上限取任务额定与官方 MJCF 额定的较小值，保持原物理关节范围。沿用已验证链的固定配置：自碰撞、扭转摩擦与椭圆摩擦关闭。这个选择公开写入版本规格；环境碰撞仍参与物理，不把该版本宣称为开启自碰撞的结果。

完整任务预算为 1200 s 模拟时间，允许慢速求解。开发墙钟和 token 不设任务级上限，实际消耗必须记录；交付后无 LLM 的评分运行使用明确记录的执行预算。887.02 s 的参考结果不被包装成旧 60 s 任务的通过记录。

固定真实柜体与折叠凳素材，以私有 seed、split 和 episode index 生成场景；开发和评测 split 分离。生成器先抽所有候选物体，再按层增添，因此同种子三层的必要实体相同。机器人与物体初态、可见目标、质量和摩擦采用声明的小范围随机化；重叠、越出房间的候选拒绝并计数。每一范围仍需边界和中间样本的物理校准，生成合法几何不等于已证明可解。

| 层 | 内容 | 验证责任 |
| --- | --- | --- |
| 1 | 目标、必要支撑物与柜体 | 证明直接够取及利用柜体等捷径不能绕过考点；验证移除必要物体后的不可行性 |
| 2 | 在同种子第一层上增添较重候选支撑物 | 指明更强身体能用的证据，并实测当前身体及与其他物体组合的能力边界 |
| 3 | 再加入固定或窄的候选干扰物 | 不可移动或不稳定来自实际物理；通过触觉、力矩及视觉反馈可发现 |

物体的角色只用于可信侧设计覆盖表。评分器不因名称或预设用途拒绝物理上可行的替代路线。`reference_v15` 保留原工程场景（包括额外彩色箱子），只用于开发诊断，不作为第一层已验收随机样本。

## 状态阶段与子任务

可信日志记录所有候选物体的位姿、线/角速度，以及分别属于左右手、左右脚、地面和中转板的实际接触。机器人关节在每个 5 ms 物理步采样，20 ms 的日志行保存区间极值和实际样本数。

| 阶段 | 必须有的实际证据 | 权重 |
| --- | --- | --- |
| support_handled | 手接触持续，并发生对应物体移动 | .05 |
| support_relocated | 由远处移至可用区域、物体落地稳定 | .15 |
| on_support | 足底几何位于物体顶面且有对应物体支撑力，持续稳定 | .15 |
| target_secured | 正确目标有持续抓持，并离开原支撑位置 | .15 |
| target_staged | 正确目标由中转板承重、速度低、双手离开 | .10 |
| descended_empty | 此前在支撑物上，随后双脚由地面承重；目标仍留在板上、双手空 | .10 |
| target_reacquired | 在实际板面释放及空手落地之后，重新抓持正确目标 | .10 |
| carried | 目标离开原处，随真实持续抓持向目标区移动的比例 | .10 |
| delivered | 正确目标落地、双手松开、运动稳定且位于目标区，机器人未倒地 | .10 |

每阶段的具体阈值和持续条件在 [relay_scoring.py](sandbox/trusted/relay_scoring.py)中冻结，并有 [反例清单](acceptance/attack_cases.json)和对应测试。最后阶段取当前值，其余记录实际发生过的里程碑；回合过程分取加权进度峰值。目标交付成功 `success` 与接力全链完成 `chain_complete` 分开报告。替代路线达到什么状态就给什么分，不从最终目标倒补未发生的阶段。

任务主指标是目标成功率 `success_rate`；接力全链率和加权过程分用于说明完成了什么。当前权重尚未经过真实 agent 对照校准，不能仅按过程分把未交付的长路线排在成功交付的替代路线之前。直接交付不会补记未发生的搬凳、中转或空手下凳。

评分规则 `relay-rubric/2.1` 将连续且有效的证据持续时间映射为阶段进度：前 0.1 s 不计分，再逐步增加至原完整持续时间；零散短接触不能累加。搬运和移位仍使用受控的几何进度。完整阶段、前序依赖和全链完成只由完整物理条件触发，部分得分不解锁后续阶段。搬动物体须有同时发生的接触和运动；目标取离原支撑面使用实际旋转后的箱底或完整投影分离；空手检查覆盖所有可移动物体；目标携带允许正常单脚支撑步态。

从板上重新取箱必须有该块板上的实际放稳、空手下凳历史，并在受控运动中真正离开支撑面。搬运距离以首次放稳的位置为起点；同板受控拉出的距离可以在离板时扣除一次，停稳换抓保留已证明的进度。松手滑移不加分，反向移动扣除进度，换板或无效证据不能重设更近的起点。离板后仍须有独立的连续空中持物位移至少 3 cm、持续至少 .25 s，并受控进入目标区；20 mm 的搬运进度容差保持不变。多次换板路线的距离归一化尚未扩展，不能宣称所有替代路线均已校准。

运行时终止和离线评分共用 [relay_safety.py](sandbox/trusted/relay_safety.py)。骨盆过低、倒置和失控倾倒仍判失败；缓慢前弯只有在初始实测足底载荷基准、持续双脚支撑及低运动速度下才获例外。当前没有完整身体触地通道；低骨盆真实下坠测试通过，不代表所有倒地和近失稳情况已完成校准。旧版运行与判分保留原源码归档，不用新规则覆盖历史 verdict。

目标区沿用现有中心位置判据，不要求完整投影包含在区域内，也不要求箱体直立。持续 .5 s 的低速、落地和无手接触是终局要求。v15 的箱子从中心约 .718 m 高度松手后侧躺稳定，属于该目标定义下的交付，不称为贴地轻放。canonical c 最后松手时箱底离地 0.61 m、箱子速度 0.39 m/s，同样在下面安全规则第 4 条的门槛之内。

沙箱子任务起点来自可信录制的 qpos/qvel 与参数快照；它们不包含求解器 warm start、控制输入或专家内部状态，不能声称精确恢复专家轨迹。专家自己的完整 checkpoint 另存这些上下文，但仍只作开发诊断。正式评测与评分拒绝中途 checkpoint。每个独立起点都需后续物理运行验证，不能只凭快照存在便标为课程已验收。

## 完整性与特殊路线

agent 在只读根文件系统、非 root 容器中运行，只能连接带令牌的白名单 RPC；评分每回合使用交付程序的新副本，不允许 LLM 或外网。进程模式仅用于开发，不算安全隔离。世界参数改变、越权、缺失/损坏/非有限日志、时间断档、超过阈值的瞬移或实际执行器越限，均返回明确的零分 VOID 结果。

需逐项实测的设计路线：直接前倾/踮脚够取、攀爬柜体、把窄物体放倒、组合多个物体、推移代替搬运、抓持目标下凳、空手板面接力，以及释放落地与抛掷的边界。合理替代路线按物理状态评分，不由隐藏用途黑名单排除。

**捷径（2026-10-21 作者决定）。** 踮脚直接够取、爬柜子下层隔板、把高窄箱放倒当台阶等捷径，安全完成就算通过；有风险的做法不鼓励，按下面的安全规则不算成功。放倒的窄箱只是换一种垫脚物，属于替代路线。踮脚和爬柜体绕过了支撑物：如果能安全完成，第一层“必要支撑物”的前提不再成立，是否抬高目标由作者再定。三种捷径都还需要实验：踮脚先做 IK 可达性检查再做物理试验；最下层隔板 0.13 m 高，但上一层隔板在 0.53 m，只能踩前沿；窄箱放倒后高 0.16–0.18 m、宽 0.18 m、2.5 kg，只在第三层出现。

**安全规则（2026-10-21 作者决定；relay-rubric/2.2 已实现，阈值已用现有录制校准）。** 规则对所有路线一样，包括正常接力路线，已写进给 agent 的任务说明（instruction 末尾与 [SDK 说明](sandbox/agent_sdk/README.md)“Safety rules”）。回合中出现任一安全事件时，`success` 与 `chain_complete` 为 false，过程分保留，不判 VOID，事件逐条列在评分结果的 `safety_events`（规则、种类、时间、实测值、阈值）。实现见 [relay_safety_rules.py](sandbox/trusted/relay_safety_rules.py)，校准记录见 [safety_rules_calibration.json](acceptance/safety_rules_calibration.json)，每个事件的正反例测试见 [test_relay_safety_rules.py](sandbox/tests/test_relay_safety_rules.py)。体重取模型质量 34.394 kg × 9.81 = 337.4 N；所有录制开始静立时的足底总载荷为 337.4–337.6 N。

1. 跌倒或险情。跌倒沿用原跌倒监测（骨盆低于 0.40 m、倒置，或骨盆上向投影低于 0.30 且不是有双脚承重确认的缓慢前弯）。险情四种：骨盆倾角 ≥30° 且 0.25 s 内增大 ≥15°（快速倾倒）；骨盆倾角 ≥45° 而双脚不是各承重 ≥10% 体重，持续 ≥0.1 s；骨盆 0.25 s 内下降 ≥0.12 m；双脚合计承重 <10% 体重且没有其他记录到的支撑（手或身体扶柜、身体压在物体上）达到 10% 体重，持续 ≥0.06 s（3 个控制步）。手拿着的箱子不算支撑。
2. 站立的支撑物不稳：脚对某物体的 0.1 s 平均承重 ≥10% 体重时，该物体最近一面偏离水平 >10°（作者门槛），或其中心从开始承重处水平移动 >3 cm。
3. 攀爬家具：脚、膝或任何非手部连杆对柜体的接触力 0.25 s 均值 ≥15% 体重（50.6 N）并持续 ≥0.25 s（踢一下、蹭一下不算）。接触力取合力大小，是竖向承重的上界。手扶柜体、用手在隔板上放取物体不算。没有脚/身体–柜体接触通道的录制报告为“未评估”，不算通过。
4. 高处丢放或抛掷：最后松手（最后一次手接触后第一个无手接触的样本）时箱底离地 >0.8 m 且此后 1 s 内箱子下落 >5 cm，或该时刻箱子速度 >1.0 m/s。两个门槛为作者定值，未改。箱子松手时已稳放在高处隔板上（1 s 内静止、下落 ≤5 cm）按“放置”处理，不算丢放；这一点需作者确认。
5. 执行器持续饱和、持续顶关节限位：共用命令模式监视器的默认阈值——腿或腰关节力矩 ≥98% 额定连续 ≥3 s（torque_saturation），关节距限位 ≤0.02 rad 且向外力矩 >50% 额定连续 ≥2 s（joint_limit_push）。共用监视器原来把骨盆倾角 >50° 当作跌倒、此后不再检查，c 在 32.6 s 的缓慢深弯之后 818 s 都没被检查；现改为只排除 H1 自己跌倒前 1 s（h1-monitors/2）。这两类告警计为安全事件，不再按时间窗扣分；抖手、摇臂仍按时间窗扣分。

校准（最大合法值 / 违规值；合法数据为 c、a、b、录制器短测、空操作与评分回合、官方 step_up 与 push_box 轨迹）：

## 参考与人工验收

[参考基线索引](acceptance/reference_v15.json)保存 v15 的原始审计、源码哈希、录像与范围。新 [参考录制入口](scripts/run_relay_reference.py)使用统一可信日志与评分器；旧的 controller 字符串事件不能伪装成新的接触证据。接口一致性、三层覆盖、边界样本、每子任务、空操作、捷径反例、同种子三次重跑、第二人独立复现均有独立状态。

人工验收使用 [human_review.json](acceptance/human_review.json)，填写实际审阅者、运行、时间区间和观察结论：是否有作弊/判据误触发；任务状态是否真实达成；是否明显违反物理或硬件限制。没有实际第二位审阅者时保留空值，脚本不会代签。

难度假设来自支撑物发现、负载步行、单脚平衡、目标操作、空手转移和再次抓取的依赖，以及感知闭环。专家调试耗时和录像时长不能替代强 coding agent 至少四小时的难度试跑；该证据目前待补。
