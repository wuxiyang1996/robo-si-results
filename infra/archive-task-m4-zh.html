与 M2 的边界

M2 由机器人通过手部接触承托货物，重点是合抬、抓持保持、载荷分配与同步下放；M4 由地面通过货台等支撑货物，机器人提供牵引或转向作用，重点是张力、滑移和牵引几何。双 G1 抬箱或抬支架运输归 M2；双 G1 拉动地面支撑的货台归 M4。

合并规则与开发顺序

  • 直线牵引与启动阻力测试并入能力探针；单 Go2 作为 M4-01／03 的能力对照，不新增主变体。
  • 原 base/hard 保留各自配置与结果，合计归入 M4-01。工具选择、团队选择、能力不对称和受阻恢复作为配置或评测条件。
  • 首批推进 M4-01 回归、M4-02 单 G1 与 M4-03 三 Go2；M4-04／05 为 P1，M4-06 为 P2。
  • 首版采用预装载、预连接。手部真实抓握、工具操作、自主连接与解绑分别验证；固定绑定不能算抓握成功，改变连接状态不能替代物理操作。

单机尝试失败不能证明协作必需；三机某种队形失败不能证明所有三机策略不可行。第三台可闲置时，评测是否值得调用。表中角色是作者侧候选设计，不向评测 agent 预告最优分工。

保留原配置的 400 N 绳索额定值、50 mm 滑移约束与目标驻留判据；G1 接口和双足监测另验，150 N 自主连接器台架结果不与原牵引参考混用。
