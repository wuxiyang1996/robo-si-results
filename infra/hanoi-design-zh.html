Hanoi：跨身体工具相性与 Self-modeling 任务设计

更新：2026-10-28。设计范围：10 个独立 task，按 embodiment、能力条件和场景分别配置、分别报告。新增设计均待物理标定与完整执行验证；本次新增物理运行为 0。原有直接操作三／四／五盘参考及其发布、验收状态保留，不能作为新增工具任务已通过的证据。

目标与范围

重点测试 cross-embodiment 工具相性、能力边界判断和 self-modeling。核心场景固定三盘；四／五盘仅作为 Dex3 的 reasoning 评测。可达、脱杆、放置和工具退出是完整执行约束，不另扩任务族。

工具配置指场景提供的候选工具集合，agent 的选择是评测结果。不同随机种子属于同一 task 的实例；不做所有身体、盘数和能力条件的全组合。这里的“公开／隐藏／边界”是能力评测条件，不替代项目原有 R9 工具三层，也不代表已获得该项认证。

Embodiment 与工具

配置 设计与控制变量
E1：G1 + Dex3 复用现有本体与末端，作为 anchor embodiment。
E2：同一 G1 + 平行夹爪 保持躯干、机械臂和固定骨盆设置，改变末端接触几何、开口与工具驱动能力。具体夹爪、安装与控制适配待确认。
E3：同一 G1 + 五指灵巧手 保持身体设置，测试多指接触分配、握持与工具驱动差异。具体五指手型号、碰撞模型与控制适配待确认。
T1：侧夹工具 薄夹口接近圆盘边缘，通过夹持力和摩擦搬运；受握柄相性、驱动行程、有效夹持力和抗滑能力限制。
T2：底部托具 从盘下建立支撑，减少侧向夹持力需求；受插入空间、工具自重、腕部力矩、抗倾覆和撤出路径限制。

10 个 task 均提供 T1 + T2。不增加无关干扰工具。盘和底座应提供真实可用的工具接近空间，例如供托具进入的浅槽；几何尺寸需标定，不能靠禁止直接手抓来制造必要性。

跨身体相性是“身体 × 工具 × 完整操作”的关系。能握住工具或提起圆盘，不等于能完成脱杆、搬运、套杆、释放和撤出。相性记录分为已验证可用、有证据支持不可用、未确定；单个控制器失败不能证明身体不可用。

至少构造一组换身体后可行工具、握持方式或协作路线发生变化的配对实例，同时保留无需改变选择的实例。不预设五指手一定更强。E3 必须展示相对 E1/E2 的可验证差异，才具备正式纳入评测的依据。

共同执行与观测协议

目标是将整叠圆盘从起始杆搬到目标杆，第三杆用于周转。一次仅搬运一个顶盘，大盘不能压小盘；整盘必须实际越过源杆顶端，之后搬到合法目标杆并套杆放置。允许合法额外移动，不以最少移动数作为成功门槛。

每次提交须正确物理支撑、完全释放并稳定 0.5 秒；全部完成后再稳定 2 秒。工具在提交时必须撤离圆盘，不得继续承托。掉盘、非法多盘操作、非法堆叠或超时按任务规则失败。

当前直接操作评分器以手接触建立抓取证据。工具版需实现并验证“机器人—工具—圆盘”的真实接触与受力链，独立检查工具撤离、正确支撑和移动合法性；不能用工具名称或 agent 声明替代物理证据。移动身体、换工具和探测的时间预算需重新标定，不能直接套用旧参考时限；本设计默认固定骨盆。

公开名义模型、硬件上限、传感器接口、目标与规则；agent 仅使用允许的自身传感器和关节动作。公开条件另提供本实例所选有效能力参数，隐藏条件不提供其真实值或边界类别。裁判参数、成功标签和工具相性答案不暴露。

标称能力实例也应在经验证的非临界范围内抽样，不让“标称”成为唯一可记忆数值。01/03、02/04、09/10 使用同一物理实例，只改变信息披露。05/06 在回合开始前设置能力参数，回合内保持固定；各自只改变一个主要因素，并保留实际可行替代路线。

Self-modeling 探测与预测

允许小幅试夹、试提、握点调整和工具姿态探测；所有条件使用相同的预算规则。记录探测次数、仿真时间和消耗。具体上限待参考执行标定后统一冻结，不让 agent 无限重置或读取真值搜索答案。

证据来自模型实际支持的传感器，例如关节跟踪误差、可见滑移、姿态变化及已实现的力／触觉。探测必须有可辨识反馈；不能只能在不可恢复掉盘后发现不适配。测试区或校准件若采用，须所有配对条件一致，不提供额外特权信息。

首次正式搬运前提交对相关工具／操作的可行性预测、置信度、关键限制与拟用方案；探测后允许更新。用后续实际执行验证，重点考察探测结论能否迁移到尚未执行的盘或转移方向。不按解释长度评分，不要求为了证伪而执行已判断不可行的动作。

05/06 的主要边界实例要求调整路线；另保留能力变化但原路线仍可行的对照实例，防止“遇到变化就换工具”的固定策略。隐藏条件的真实参数范围与评测种子按可信侧配置封存。

四／五盘 reasoning eval

07/08 保持已知能力和足够的操作余量，盘数以外的物理条件尽量配对；随盘数产生的几何变化应记录并检查，不把物理难度增加归因于推理。三／四／五盘经典最少移动数分别为 7/15/31。

对每个 reasoning task 运行两种诊断模式：自主生成与更新符号计划；提供合法符号移动序列后仍由 agent 完成物理执行。报告两种模式的成功率差异、合法性错误和额外移动。后者仍失败时，结合状态估计与接触日志分析执行原因。该对照属于同一 task 的评测模式，不增加 task 数量。

配对关系与指标

对照 主要解释
01 / 02 / 09 同场景、同工具、能力公开，比较跨身体相性。
01 ↔ 03；02 ↔ 04；09 ↔ 10 同物理实例，仅改变能力信息披露，分析探测与 self-modeling。
03 ↔ 05；04 ↔ 06 同身体、同披露协议，改变关键能力参数，分析边界与策略适应。
01 ↔ 07 ↔ 08 已知能力下比较三／四／五盘规划与执行。

主指标为完整任务成功率，按每个 task 独立报告样本数和结果。辅助指标包括：工具／操作可行性预测准确率及置信度校准、能力高估与低估、探测前后预测改善、探测成本、边界变化后的有效策略调整、非法与额外合法移动，以及滑移、脱杆、放置、撤出等失败阶段。

相性标签未确定的样本不强行计入预测准确率。替代工具、环境借力和双手协作只要符合物理与任务规则均应接受；有效新路线出现时更新相性标签。
