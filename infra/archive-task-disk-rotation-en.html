The high-level controller selects the active contact mode from measured state. Low-level control uses force admittance, local IK, joint PD and model gravity/Coriolis feedforward, all within authored torque limits. This is the implemented feedback expert; the initial MPC proposal is not presented as implemented.

Reproduction, release materials and acceptance

The release scope is the native expert, generation code and audited trajectories for these two configurations. All six executions and two replays pass physics and mapping audits. The Panda model retains upstream simplified inertias; hardware transfer, random-domain coverage, arbitrary skill composition, generic MPC and necessity of two arms/recontact are not established.

The user approved the current reference materials; 0.1.0 is a stable release.

Approval covers these two configurations and the declared evidence scope. Independent-person reproduction, hostile-code sandboxing and random-domain generalization remain unverified; approval does not change those technical results.
