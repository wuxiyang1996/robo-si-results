2. 共享场景与规则

目标。 将指定长箱从起始区运过 90° L 型通道，完整放入目标区，完成合法支撑转移与释放，所有机器人安全停稳。任务目标不指定必须使用工具、固定抓点或固定角色。

物体与环境。 长箱基准尺寸为 2.25 × 0.35 × 0.24 m；轻载为 0.25 kg；通道基准净宽为 1.8 m。M2-2 保持 M2-1 的箱体、通道和目标区；只调整为容纳另一种身体所必需的合法起始站位，并记录差异。M2-3／4 共享同一重载值、重心、箱体尺寸、地面、通道和目标区。M2-5 在 M2-3 的布局上增加一个可移动障碍及其合法暂存区；M2-6 保持 M2-5 的所有物体状态，仅增加第三台 G1 及不干涉的起始站位。

重载值。 先从 0.25、0.5、1、2 kg 逐级检查，再决定是否测 3–4 kg。正式重载值记为 m_H，筛查通过前不填写成功参数；9 kg 不作为本轮必须成功的目标。历史 2 kg 支架取箱失败只说明该次控制与配置未建立稳持，不等于硬件承载上限。

工具。 本轮只保留低矮滚轮拖板及必要连接件，作为一套运输工具。M2-1 保留原场景；M2-2 的主比较不增加工具。M2-3／4／5／6 的工具可用条件提供相同工具库存与放置位置。工具初始与货物分离，连接件不得远程吸附。装载、对接、牵引、转向、制动、卸载和脱离都需要可执行的物理过程。预装载或预连接仅可单列为技能诊断，不计为完整任务见证。

最终状态。 本轮核心配置以箱体直接稳定支撑在目标区地面为最终交付，机器人和运输连接件脱离货物。箱体留在拖板上只能记录为运输阶段完成，不能代替完整交付。工具本身无需返回起始位置，但应稳定停放，不压住货物或妨碍机器人结束。

允许动作。 合法抓持、推拉、临时放置、重新抓持、重新站位、角色交换和工具操作均可使用。不得运行中改写物体或机器人位姿、注入隐藏承托外力或绕过碰撞；初始状态由环境统一构造。备用策略只要满足当前配置的公开规则，也应得到认可。

3. 六个任务的详细描述

M2-1 · 双 G1 轻载协同搬运

初态与目标： 两台 G1 在长箱两端的冻结起始状态准备，从地面搬起 0.25 kg 长箱，穿过完整墙体的 L 型通道，放到目标区并释放。沿用发布场景的初态、控制接口、预算和评分。

Agent 任务描述： 控制两台机器人，将地面上的指定长箱运过 L 型通道并放入目标区。遵守公开的接触、执行器与稳定性约束，交付后释放长箱并停稳。

操作与观测重点： 双端接近与抓持同步；起身时箱体姿态和两端承重；转角处箱体端点与机器人包络；到位制动、同步下放与撤手。技能交接应使用实际位姿、速度、接触和支撑状态，不能只按控制阶段名称推进。

验收： 原 grasp、lift、turn、transport、lower、place 六阶段评分原样保留，按发布包中的实际版本复现。已有参考证明固定配置可完成，不证明随机泛化、传感器反馈规划或独立技能任意拼接。

M2-2 · G1 + Stretch 轻载异构搬运

初态与目标： 将 M2-1 的一台 G1 换成选定型号的 Stretch，保持箱体质量、尺寸、通道和目标不变。起始站位按双方真实工作空间设置，不能预先绑定箱体或使用隐藏支撑。

Agent 任务描述： 使用当前两台机器人，将指定轻箱从地面送到目标区并稳定释放。根据各自可用关节、末端和移动能力选择抓持方式与配合动作。

操作与观测重点： 确认可共同作用的接触位置和高度，协调 G1 步态与轮式底盘，处理 Stretch 伸臂、腕部与底盘稳定性。转向时允许改变队形、临时放置和重抓；不要求双方对称承重，也不强制复制双 G1 的轨迹。

验收： 从正常地面初态连续完成交付，并满足共享终态及过程约束。先独立验证 Stretch 的可达、夹持、升降与受力移动，再做完整通道。若无工具轻载路线尚不可行，记录失败并重新审核配置，不能将其自动解释为成功的工具发现。

对照： 与 M2-1 比较伙伴替换后的接触策略、角色分配和协调代价；同时注明旧六阶段分数与新任务判据不可直接当成同一量表。

M2-3 · 双 G1 较重长箱搬运

初态与目标： 保持轻载场景的几何与重心设置，将长箱质量改为经筛查确定的 m_H。工具可用条件下，拖板与连接件位于可访问工具区，均未装载、未连接。

Agent 任务描述： 将指定长箱运至目标区。根据观察与允许的试探判断抓持和运输是否可行，可选择直接搬运或使用现场工具，最终在地面交付并释放。

操作与观测重点： 观察夹持滑移、关节受力、两端高度与姿态、步行稳定性；根据实际能力分配载荷，选择速度、抓持与路径。在不足以确认稳定搬运时，允许停止推进、合法下放和重新规划。

验收： 每个候选负载依次检查抓持、抬升稳持、短距离运动、转弯及下放，保留失败阶段与原因；完整成功必须来自一条连续运行。工具可用组的合法工具解同样计成功。作者另行验证直接搬运参考，用于筛选与 M2-4 的能力差异，不能把直接搬运写成 agent 唯一解。

M2-4 · G1 + Stretch 重载机制选择

初态与目标： 与 M2-3 使用同一 m_H、箱体、通道、工具、目标和信息条件，仅替换一台机器人。Stretch 绑定与 M2-2 相同的型号和控制器。

Agent 任务描述： 使用当前两台机器人及现场可用物体，将长箱完整送达目标区并在地面释放。自主判断运输方式并分配双方职责。

操作与观测重点： 判断直接抓持与移动的裕度，探索拖板能否装载、连接、稳定承载和通过转角；根据双方实际能力分配装载、牵引、定位和卸载工作。探测和恢复都计入回合预算。

验收： 若采用工具，必须完成从地面货物到装载、运输再到地面卸载的完整过程。某个工具由人工预置到工作状态不计自主工具使用。直接搬运若合法成功，也必须接受。

待验证假设： 希望找到双 G1 可直接搬运，而 G1 + Stretch 直接搬运受限、使用拖板明显获益的共同负载。若筛查未形成该差异，应调整候选负载或明确报告假设未成立，不通过禁止直接搬运制造工具必要性。

M2-5 · 双 G1 重载运输与清障

初态与目标： 在 M2-3 的转角操作区增加一个可移动箱体和明确的合法暂存区。障碍阻挡直接运输的必要空间，但移动后应存在完整通过路径。保留相同长箱、负载与工具库存。

Agent 任务描述： 将指定长箱送到目标区。现场有可移动物体，可在公开规则允许的范围内调整其位置；最终长箱、被移动物体和机器人都应稳定停放在各自允许区域。

操作与观测重点： 判断障碍是否确实阻挡箱体或机器人的扫掠空间；选择起箱前清障，或途中合法放箱、清障、重抓等顺序；避免清障后再次封堵路线。障碍的质量、摩擦、尺寸与暂存区必须先验证，不能用一个不可操作的障碍替代规划难度。

验收： 满足共享交付条件；被移动障碍稳定置于允许区域，不侵入目标区或堵塞必要结束空间。允许合法绕行，不强制移动障碍；若出现轻易绕行，应报告该实例未有效检验清障。临时放置、重抓和清障顺序不预设为必经阶段。

对照： 与 M2-3 比较障碍带来的计划变化和执行成本。首次版本使用可见的静态初始障碍，不增加突然出现的动态障碍。

M2-6 · 三台 G1 的搬运与清障分工

初态与目标： 完整复用 M2-5 的物体位置、障碍、暂存区、负载和工具，仅增加第三台同型号 G1。保留原两台的起始位置，第三台在不干涉初态和通路的合法位置启动。

Agent 任务描述： 控制当前三台机器人，将长箱送到目标区，并妥善处理路径上的可移动物体。自主分配工作，结束时所有机器人均稳定停放。

操作与观测重点： 自主决定第三台是否清障、搬运工具、参与承重、提供定位或等待；协调机器人之间的空间占用、工作顺序与交接。两台搬运、一台清障是作者候选策略，不向 agent 指定，也不强制三台同时接触箱体。

验收： 与 M2-5 使用相同货物和障碍终态规则，增加第三台机器人的稳定性与碰撞检查。第三台未参与不自动判失败；记录闲置、等待、相互阻挡与实际贡献。

对照： 在匹配预算和相同场景下比较 M2-5／6 的成功率、时间、总机器人动作成本、临时放置及重抓次数。第三台减少等待但增加协调成本也应如实记录，不能因机器人数量增加就宣称协作更好。

4. 评分、观测与实验对照

M2-1 冻结，新配置单独评分。 M2-2～6 的最终成功依据目标包含、合法支撑与释放、机器人稳定和过程约束，不能要求所有团队满足“四手接触”。损伤若没有真实破坏模型，只报告接触力、冲击或跌落等代理约束。碰撞应区分合法手部／工具／障碍接触与非允许碰撞，不能把正常清障接触算失败。

数值阈值先标定再评测。 新配置的稳定驻留、速度、倾角、接触力、冲击、力矩裕度、目标边界容差和预算均为待冻结参数；不得将 L1 数值未经验证套给 Stretch 或三机。当前工作树与发布清单的评分版本需要核对，L1 复现以冻结发布包为准。

公共观察与隐藏参数。 Agent 只能读取声明的视觉、机器人本体状态、触觉及力反馈等接口；不同机器人传感器不必相同，但要记录。未知条件中不暴露物体质量、摩擦、隐藏能力缩放或正确工具。作者侧物理真值用于验证，不进入 agent 输入。每次策略判断记录预测可行性、置信度、依据及探测后的更新。

主要比较： ①↔②、③↔④比较身体适配；①↔③、②↔④比较负载变化；③↔⑤比较障碍；⑤↔⑥比较团队规模。负载对照先使用双方均无工具的条件，工具收益另由同一任务的消融估计；其余比较也必须匹配工具可用性和信息条件，记录必需的站位差异。历史 L1 只提供原范围参考；如需统一实验统计，应新增受控评测并单独记账，不能改写旧结果。

工具与探测消融： 在 M2-3／4 中使用“工具可用／不可用 × 专门探测允许／不允许”的四组条件，加真实参数已知的参考组。正常执行反馈在各组均可用；专门辨识动作的边界在实验前定义。工具、信息条件和重复 seed 不另算任务。总仿真时间、动作和观测预算应可比；三机同时报告总团队成本与每机成本。

单机检查： 给合理单机策略相同物体、工具与可比预算，区分协作必要性和效率收益。单次单机失败不构成单机不可行证明。相同 seed 重放不构成随机覆盖。

统一记录： 成功与失败阶段、箱体轨迹、机器人状态与执行器力矩、接触与支撑、双方／三方载荷、工具状态、障碍位置、角色变化、探测次数与成本、可行性预测、恢复、放置和重抓次数、等待与相互阻挡、完成时间、视频和配置哈希。承重比例用于诊断，不强制各机器人平均分担。
