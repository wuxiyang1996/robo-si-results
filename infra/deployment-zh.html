修复内容

  • 分别提供 Windows、Linux 的带 SHA-256 依赖锁；M1/M2 的 agent 容器也锁定完整依赖。
  • M2 不再依赖原机器盘符；保留冻结源码与求解器哈希校验。
  • 补齐 Hanoi / Assembly 的 7 个共享元数据文件。
  • 补齐 H4 缺少的录像模块及原版场景素材，保留来源和许可证说明。
  • 启动前核验模型、材质、贴图与源码；自动保留测试日志和安装回执。
  • Linux Hanoi 与 H3 重支撑物采用已验证的严格数学配置，保留原控制器、步长与限值。
  • H5 修复录像错误输出管道阻塞，并固定已完成纹理录像验证的 Mesa 25.0.7。
  • Linux H6 原控制器采用严格数值计算后完整物理运行通过：1.0、585.87 秒；默认无录像，不宣称新的 Linux 完整录像验收。
  • Assembly 按发布流水线使用第一层闭环入口；补齐 H4 资产生成模块。
  • Linux M1/M2 增加本地 socket 转发；M4 base 使用较慢转弯的公开控制参数，原限值不变。
  • Linux M3 从初始场景完整物理运行通过：反馈行走、实测姿态返回、落地脱手与稳定交付，1.0、无告警；补齐含许可证的 WBC 模型。默认无录像，不宣称新的完整录像验收；分段快照实验不计完整通过。

下载与运行

需同时拥有私有 GitHub 仓库与 HF 数据集权限，并安装 uv 0.12.5。入口会下载指定 Python；VC++ 运行库、GPU 驱动和 Docker 等主机依赖参见完整说明。共享机器必须传入现有队列适配器。

Windows · PowerShell

.\bootstrap.ps1 -Action install -RootPath C:/rs
.\bootstrap.ps1 -Action prepare -RootPath C:/rs -Task all
.\bootstrap.ps1 -Action check -RootPath C:/rs -Task all
.\bootstrap.ps1 -Action run -RootPath C:/rs -Task M2 -RunName test-01

Linux · Bash

bash bootstrap.sh install --root /data/rs
bash bootstrap.sh prepare --root /data/rs --task all
bash bootstrap.sh check --root /data/rs --task all
bash bootstrap.sh run --root /data/rs --task M2 --run-name test-01
