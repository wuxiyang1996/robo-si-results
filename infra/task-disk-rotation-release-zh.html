消融告诉了我们什么

  • DR-02：两项自适应策略超时的相同隐藏物理场景，旧 fixed_contacts 分别在 31.94 s、34.40 s 成功。分区摩擦本身不证明换点必要。
  • DR-04：原固定接触对照在 14.02 s 发生非预期碰撞；换点参考解在标称配置及三个扰动配置成功。该结果支持这组控制器的差异，不是所有固定接触策略的不可行证明。
  • DR-05：双臂对照初次因配置合并错误零步退出。修正为实际双臂后 43.54 s 成功；单臂标称参考为 98.50 s。原错误保留，不算作物理失败。
  • DR-09：同一双机器人场景中，Panda-only 控制器接触获取超时；Stretch-only 控制器发生碰撞。协作参考成功，但这不是所有单机器人策略不可行的证明。
  • DR-08：直接双手接触已经成功，参考解未使用附件；工具必要性尚未建立。

接口验证的范围

Agent 仅获得机器人安装的 RGB 相机、关节 proprioception、公开目标与自身关节限制。Stretch 包含按 URDF 标定的头部相机。无物体真值、材质系数、奖励或 simulator setter。开发使用普通进程，评测使用 Bubblewrap 命名空间隔离与只读 OCI 文件系统；只有工作目录和认证 RPC 通道开放。

空操作为有效 0 分；越权操作被拒绝且运行判为 VOID；两轮 grading 使用新的工作目录。公开参考动作通过接口完整成功，但这是 open-loop integration witness，不是独立 coding agent 成绩。

正式准入边界

人工视频审核、第二人复现签署以及独立 coding agent 闭环成绩仍待补充。当前移动模型为 Stretch 3；G1 固定骨盆。DR-I01 为 unknown。未放宽物理阈值，未修改共有准入检查器，也未替人工签署。
